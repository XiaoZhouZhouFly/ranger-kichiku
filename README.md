把 LR 手遊角色的動畫拿來玩：播放任何角色的技能與動作、拆開零件亂改、剪成惡搞影片，或讓兩隻角色上場對打。打開網頁就能用，不用安裝，手機也可以。

### 👉 [點這裡開啟網站](https://xiaozhouzhoufly.github.io/ranger-kichiku/)

## 功能

### 🎬 單人惡搞

<img src=".github/single.gif" alt="單人惡搞示範：恐龍熊大的技能被重複、鏡像、變色、放大" width="300" align="right">

- **找角色**：輸入名字搜尋、從角色庫一隻隻瀏覽，或按 🎲 隨機挑一隻，資料每天自動更新。
- **播放動作**：待機、移動、普攻、技能 1、技能 2、被擊退，技能會一起顯示圖標、說明與投射物。
- **零件調整**：角色身上每個零件都能單獨隱藏、放大、旋轉、換顏色。
- **惡搞剪輯**：用時間軸把片段重複、倒放、變速、鏡像、放大震動，也有現成的示範和隨機惡搞；改錯了可以按上一步。

<br clear="right">

### ⚔️ 雙人對戰

左右各挑一隻角色（也可以 🎲 隨機），三種對戰類型：

| 類型 | 適合 | 怎麼打 |
| --- | --- | --- |
| **經典對戰** | 拍好看的對打片段 | 照招式順序輪流出招，可以選你來我往、隨機或自己排招 |
| **真距離對戰** | 比較攻擊距離的差異 | 依各自的攻擊距離與移動速度走位、同時出手，距離短的一方有傷害加成；距離和移動速度都能自己調 |
| **原始數值對戰** | 用遊戲數值硬碰硬 | 照資料庫的等級、攻防、爆擊、閃避、技能倍率自動對戰，可調血量倍率，還有金手指可以改數值 |

會召喚的角色放技能時，召喚物也會出場一起打；「將敵人召喚為我方夥伴」的角色會叫出對手的複製體幫忙打，每方場上數量有上限可調（預設 3）。真距離與原始數值對戰裡，召喚物也會被打、會被打倒：普攻打最前面的敵人，技能打到範圍內的所有敵人；召喚物的攻擊、血量比例都能自己調。最後一擊會顯示 K.O.，再用黑白慢動作 REPLAY 重播一次。競技場可以換成白、黑、綠幕，或上傳自己的背景圖。

### 📤 輸出

- 單人與雙人畫面都能直接輸出成 MP4 影片，可選 16:9、1:1、9:16；支援的瀏覽器會逐格輸出，不用等即時播放、也不會掉格。
- 普攻命中、技能發動、技能命中都有音效（多種預設或自己上傳），可以再加上自己的背景音樂；上傳過的檔案會記在這台裝置，下次不用再傳。
- 分享按鈕：複製連結或下載專案檔，朋友打開就是同一個畫面；專案檔也能拿來備份自己的作品，按旁邊的「開啟專案檔」還原。

## 最近更新（v4.12）

- 召喚物平衡：召喚物會被打倒，可調攻擊、血量比例，每方上限預設改為 3；複製體只會複製對手本人。
- 召喚補齊：進化型改用同系列的召喚動畫、亡者歸來一次 2 個棺木、新增對手複製體，並可設定每方召喚物上限。
- 真距離、原始數值對戰可以分別設定雙方的移動速度。
- 原始數值對戰：普攻改用防禦公式，閃避、技能閃避、技能抗性最多 95%。
- 頁尾顯示版本號，可一鍵複製回報資訊；新增自動健檢，沒通過就不發布。
- 新增兩隻自製測試角色「【自製】方塊騎士」「【自製】圓圓法師」，並在網站與 README 加上非官方聲明。
- 錄影改成逐格輸出：比即時錄快好幾倍、不掉格，音效和畫面完全對齊（Chrome、Edge 等支援的瀏覽器）。
- 修正 iPhone／iPad 錄的影片在內建播放器結尾卡住的問題（v4.8.1）。
- 新增上一步／下一步：單人的惡搞片段和零件調整改錯了可以復原。
- 自己上傳的音效、背景音樂、競技場背景會記在這台裝置，重新整理不用再上傳。
- 開網頁更快、暫停時更省電，連續換角色也不會越來越吃記憶體（v4.7.1）。
- 新增分享：按播放列的分享鈕，可以複製連結或下載專案檔，朋友打開就看到同一個畫面、同一場對戰結果。
- 新增開啟專案檔：分享鈕旁的按鈕，單人、雙人的檔案都能開，自動切到對應模式。

### 運作方式

- 每天台灣時間 03:17 自動檢查上游，有新角色或更新才下載變動的部分。
- 只新增、不刪除：上游刪檔或消失時，已同步的角色全部保留，網站照常運作。
- 上游連不上時會跳過，不會清空現有資料。
- 想立刻更新：到 **Actions → 同步角色資料並發布網站 → Run workflow**。
- 每次發布前會先跑**自動健檢**，全部通過才更新網站。結果在 Actions 該次執行的 **Summary** 頁面（表格列出每一項）；失敗時網站維持上一個正常版本，GitHub 會寄信通知，失敗截圖在同一頁下方的 `healthcheck-screenshots`。
- 在自己電腦跑健檢：`cd tests && npm install playwright && npx playwright install chromium`，再回到上一層執行 `node tests/healthcheck.mjs .`。

### 注意

- 公開 repo 若 60 天沒有任何更新，GitHub 會暫停排程並寄信通知，到 Actions 頁面按 **Enable workflow** 即可恢復。
- 資料約 570 MB，在 GitHub Pages 1 GB 上限內。
